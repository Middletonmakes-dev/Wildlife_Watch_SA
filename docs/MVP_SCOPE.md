# MVP scope

## In scope

- Mobile-first Flutter Web/PWA starter targeting Android browsers and iPhone Safari
- Anonymous reporter experience with Firebase-backed callable submission when configured
- GPS and manual tap/drag map pin, incident classification, optional photo/note/direction
- Confirmation and centrally maintained guidance
- Sanitised public map and basic protected admin foundation
- Typed data models, privacy projection, Firebase rules, indexes and Functions
- Support/donation placeholder, synthetic sample data, tests and developer documentation

## Out of scope

Native stores, profiles, social features, gamification, push notifications, AI identification, complicated offline sync, volunteer dispatch, sensors, municipal integrations, multi-tenant SaaS, subscriptions, advertising and advanced hotspot algorithms.

## Explicit limitations

The starter keeps draft state in memory and does not promise offline submission. Tile-provider production use, authority-approved conservation wording, Firebase App Check configuration, admin claims and photo content verification require manual follow-up.
