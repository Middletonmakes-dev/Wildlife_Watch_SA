# Conservation guidance

Current draft wording: “Only help if it is safe for you. If a live tortoise is on the road, move it off the road in the same direction it was already travelling. Do not relocate it to a different area.”

This text is kept in `lib/app/config/guidance.dart` so it can be revised without restructuring the UI. It remains draft content and must be verified with the appropriate conservation authority before public launch. The application must never encourage a person to enter traffic or handle an animal when doing so is unsafe.

Source checked 2026-10-03: [CapeNature: Get educated, Save our tortoises](https://www.capenature.co.za/get-educated) supports moving a tortoise found in a road safely in its existing direction. This supports the draft's direction principle; it does not constitute project approval, injured-animal guidance or an emergency contact arrangement. Confirm complete local wording and contacts with the responsible authority before launch.
