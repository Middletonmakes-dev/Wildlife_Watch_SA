# Operations

## Cost monitoring

Track Firebase document reads/writes, Storage bytes and operations, Functions invocations/egress, Hosting transfer, map/tile provider usage and future payment-provider fees. Watch for anonymous account churn, repeated photo retries and public map read growth. Avoid caching Firebase responses or private photos in the PWA shell.

## Data quality and safety

Review pending reports, duplicates and obvious spam through claims-protected administration. Keep exact exports access-controlled. Define retention/deletion and incident response before the pilot. Keep conservation guidance review status visible to maintainers.

## Recovery

The callable request ID makes client retries idempotent. A photo failure does not erase the core report. Offline queueing, automated backup/restore drills and retention tooling remain future operational work.
