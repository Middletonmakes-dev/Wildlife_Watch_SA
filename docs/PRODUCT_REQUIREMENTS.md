# Product requirements

The reporter should open a link or QR code, choose a location, classify the incident, optionally add a photo/note/direction, submit and receive useful guidance without visible account setup. GPS is offered early, but denied/unavailable/low-accuracy location must leave a usable manual pin path.

The public map exposes only accepted privacy-protected projections and supports incident-type and date filtering. Administration eventually needs exact records, private photos, accuracy, notes, status, counts, filters and safe CSV export behind authorised claims.

Privacy, mobile performance, weak-network error handling and an optional non-blocking photo are first-class requirements. No advertising analytics or payment processing is enabled.
